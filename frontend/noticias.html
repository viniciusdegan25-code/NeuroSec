🚨 CRÍTICA // CVSS 10.0 CVE-2024-3094

Ataque de Injeção de Backdoor em Supply-Chain no XZ Utils (liblzma)

Um agente malicioso utilizou técnicas de engenharia social ao longo de dois anos para obter permissão de mantenedor no pacote de compressão XZ Utils. O backdoor foi injetado nos arquivos de build oficiais para permitir bypass de autenticação e Execução Remota de Código (RCE) no OpenSSH.

Fonte Oficial: CISA Alert // Reported Supply Chain Compromise in XZ Utils ↗
🛡️ Mitigado pelo SCA do NeuroSec
⚠️ ALTA // SUPPLY-CHAIN 100.000+ Sites Afetados

Comprometimento do CDN Polyfill.io Injeta Scripts Maliciosos Globalmente

Após a compra do domínio oficial `polyfill.io` por uma operadora terceirizada, a rede CDN passou a injetar scripts JavaScript maliciosos e ofuscados diretamente nos navegadores dos usuários, sequestrando tráfego web e redirecionando para páginas falsas.

Fonte Oficial: Cloudflare Security // Polyfill.io CDN Hijack & Mitigation ↗
🛡️ Mitigado pelo DAST & CSP Audit
⚛️ PADRÃO OFICIAL // PQC NIST FIPS 203 / 204

NIST Publica Padrões Finais de Criptografia Pós-Quântica (ML-KEM & ML-DSA)

O Instituto Nacional de Padrões e Tecnologia dos EUA oficializou os padrões mundiais de criptografia pós-quântica (Kyber e Dilithium). Infraestruturas críticas e sistemas bancários devem iniciar a migração imediata de chaves RSA e ECC para resistir a futuros computadores quânticos.

Fonte Oficial: NIST.gov // Post-Quantum Cryptography Final Standards ↗
🛡️ Mapeado pelo SAST do NeuroSec
